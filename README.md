# Pangasinan Heritage Digital Showcase

A digital platform promoting the iconic heritage sites of Pangasinan, built using modern web technologies and deployed via GitHub Pages.

## Project Information

- **Student Name:** Jethro Andrei Ringais
- **Selected Framework:** Vue + Nuxt.js 3
- **Live Website:** https://devringais-collab.github.io/Pangasinan-Heritage/

## Features

- 🏝️ Showcase of iconic Pangasinan heritage sites (Hundred Islands, Bolinao Lighthouse, Balungao Hot Spring, Dasol Beach)
- 📱 Mobile-first responsive design
- ⚡ Static Site Generation (SSG) for lightning-fast performance
- ♿ WCAG 2.1 AA accessibility principles
- 🎨 Atomic Design System (Atoms, Molecules, Organisms)
- 🚀 Deployed via GitHub Pages

## Tech Stack

- **Framework:** Nuxt.js 3 (Vue.js)
- **Styling:** Custom CSS with design tokens
- **Deployment:** GitHub Pages
- **Build Tool:** Vite
